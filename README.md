# CalculoIR-JUnit

Projeto desenvolvido para a matéria de Qualidade e Testes de Software afim de praticar testes de software com JUnit 5, utilizando Java e Maven para verificar o comportamento de um método de cálculo de Imposto de Renda (IR) a partir de diferentes valores de renda.


## Como executar o projeto

### Pré-requisitos

- Java JDK instalado.
- Apache Maven instalado.

### 1. Clone o repositório

```bash
git clone https://github.com/BONJIU/CalculoIR---JUnit.git
```

### 2. Entre na pasta do projeto

```bash
cd CalculoIR---JUnit
```

### 3. Execute os testes

```bash
mvn test
```

O Maven irá compilar o projeto, executar os testes JUnit e apresentar o resultado no terminal.
